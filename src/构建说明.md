# BuBu 1.6.0 源码

在本目录运行 `dotnet build MDSkinSwap.csproj -c Release`，生成 `bin/Release/bubu.dll`。如果游戏安装在其他目录，追加 `-p:GameDir="游戏目录"`。项目引用已由 MelonLoader 生成的 IL2CPP 程序集。

- `SkinCatalog.cs` 读取内置预设、注册角色和自定义皮肤。
- `LegacySkinImport.cs` 首次启动读旧 `Mods/bubu.pak`，将有改动的角色导出到 `Custom Skin`，并保存迁移记录。
- `SkinSwitch.cs` 管理 MelonPreferences 选择、Unity 贴图和材质的切换与还原。
- `SkinMenuView.cs` 绘制菜单、角色列表和选择页。

`Official-1.5.4.pak` 是固定的迁移基线，也提供 1.6.0 的内置皮肤。以后替换官方皮肤时，请保留该基线，用 `-p:PresetPack="新预设包路径"` 将新的完整 PAK 编译为内置资源。当前预设对应的角色和贴图由 `SkinCatalog.cs` 声明。新资源的正式发布包仍只包含一个 DLL。

自定义目录格式和皮肤分组参见发布包的 README。
